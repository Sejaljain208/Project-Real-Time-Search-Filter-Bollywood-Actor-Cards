# Real-Time Search Filter (Bollywood Actor Cards)

A simple and interactive frontend project built using HTML, CSS, and JavaScript.
This project displays Bollywood actor profile cards and filters them in real time as the user types in the search box.

## Features

* Real-time search filtering
* Dynamic card rendering using JavaScript
* Clean and modern UI
* Search by actor name
* Responsive card layout
* Blurred card background effect

## Tech Stack

* HTML5
* CSS3
* JavaScript (DOM Manipulation)

## How It Works

* Actor data is stored inside a JavaScript array
* Cards are created dynamically using `document.createElement()`
* As the user types in the search input, cards are filtered instantly
* Matching actor cards are displayed in real time
